# pairexx Frontend

Modern anonymous chat web application built with Next.js 14.

## Tech Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Zustand** (State Management)
- **TanStack Query** (API Fetching)
- **Lucide React** (Icons)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Features
- Anonymous session creation with `device_id`
- Real-time matchmaking with polling
- WebSocket-based chat with typing indicators
- Modern dark-themed UI with premium animations
